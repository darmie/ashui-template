# ashui-template

Native, reactive UI for Haxe.

## Requirements

Haxe · Ash · ashui · ashui-components

## Get started

Run in this project's terminal:

```sh
haxe build.hxml && ash --preset application bin/app.hl
```

[Documentation](https://github.com/rayzor-blade/ashui)

Install the UI libraries with `haxelib install ashui` and `haxelib install ashui-components`. Their native libraries are staged beside the compiled bytecode automatically.

To build a native executable, run `ash --build bin/app bin/app.hl`.
